# Wildfire - Concept Art Prompts
## Leonardo.ai Optimized

---

## How to Use These Prompts

### Leonardo.ai Settings (Recommended)
- **Model:** Leonardo Phoenix or Leonardo Diffusion XL
- **Style:** Illustration or Anime (either works well for game character concepts)
- **Resolution:** 1024x1024 (square) for character sheets, 1024x768 (landscape) for full scenes
- **Guidance Scale:** 7-9 (higher = more prompt adherence)
- **Number of Images:** 4 per prompt (pick the best, iterate)

### Workflow
1. Run each prompt to generate 4 variations
2. Pick the best result for each class
3. If needed, re-run with tweaks noted in the "Iteration Tips" section
4. Save your favorites to a `Concept Art` subfolder
5. Use these as reference when pixel-arting the actual 16x24 sprites

### Universal Style Prefix
Paste this before EVERY character prompt to maintain visual consistency:

```
Pixel art RPG character concept art, steampunk sci-fi fantasy style, top-down game character reference sheet, full body front view and side view, clean lines, vibrant colors on neutral background, detailed equipment and silhouette, inspired by Final Fantasy and Phantasy Star Online character design,
```

### Universal Style Suffix
Paste this after EVERY character prompt:

```
, character design sheet, game art, concept art, pixel art inspiration, clean background, high detail, no text
```

## Character Class Prompts

### Tips for All Classes
- Run each prompt once for the **male variant** and once swapping "male" for "female" (or "masculine" / "feminine")
- If Leonardo generates too much background clutter, add `simple background, white background` to the suffix
- If designs look too modern/realistic, add `stylized, anime-inspired` to push toward game art

## Prompt Iteration Cheatsheet

If results aren't right, try adding these modifiers:

| Problem | Add to Prompt |
|---|---|
| Too realistic | `stylized, anime-inspired, hand-drawn feel` |
| Too cluttered background | `simple background, white background, isolated character` |
| Proportions too normal | `chibi proportions, exaggerated features, game sprite style` |
| Not steampunk enough | `brass gears, copper pipes, steam vents, mechanical parts, rivets` |
| Colors too muted | `vibrant saturated colors, bold color palette` |
| Character too generic | Add more specific prop details (weapon shape, unique accessory) |
| Multiple characters when you want one | `single character, solo, one person` |
| Wrong perspective | `front-facing, straight-on view, character reference sheet` |
